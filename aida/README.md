# Telegram-бот выдачи видеосерий (aiogram v3)

Бот выдаёт пользователям видеосерии по сохранённому `file_id` без скачивания тяжёлых файлов на хост. Есть обязательная проверка подписки на канал, админ-панель, управление рекламными постами и настраиваемый интервал их показа.

## Требования

- Python 3.10+
- aiogram 3.x
- aiosqlite
- python-dotenv

## Локальный запуск

1. Клонируйте репозиторий:
   ```bash
   git clone <repo>
   cd aida
   ```

2. Создайте виртуальное окружение и установите зависимости:
   ```bash
   python -m venv .venv
   .venv\Scripts\activate        # Windows
   source .venv/bin/activate     # Linux/macOS

   pip install -r requirements.txt
   ```

3. Скопируйте `.env.example` в `.env` и заполните свои значения:
   ```bash
   copy .env.example .env        # Windows
   cp .env.example .env          # Linux/macOS
   ```

   Обязательно укажите:
   - `BOT_TOKEN` — токен от @BotFather
   - `ADMIN_IDS` — ваши Telegram ID через запятую
   - `REQUIRED_CHANNEL_ID` — числовой ID обязательного канала (-100...)
   - `REQUIRED_CHANNEL_URL` — ссылка-приглашение на канал
   - `STORAGE_CHANNEL_ID` — ID канала-хранилища видео

4. Добавьте бота в администраторы обязательного канала (права на просмотр участников) и в канал-хранилище.

5. Запустите бота:
   ```bash
   python main.py
   ```

## Деплой на Bothost / VPS

### Bothost (Python-хостинг)
1. Загрузите файлы бота на хостинг.
2. Создайте `.env` с данными продакшена.
3. Установите зависимости через терминал хостинга:
   ```bash
   pip install -r requirements.txt
   ```
4. Запустите `python main.py` (или через их панель управления процессами).

### VPS (systemd)
1. Установите Python 3.10+, git, pip.
2. Клонируйте репозиторий, настройте `.env`.
3. Создайте service-файл `/etc/systemd/system/aida-bot.service`:
   ```ini
   [Unit]
   Description=Aida Telegram Bot
   After=network.target

   [Service]
   Type=simple
   WorkingDirectory=/opt/aida
   ExecStart=/opt/aida/.venv/bin/python /opt/aida/main.py
   Restart=always
   User=aida

   [Install]
   WantedBy=multi-user.target
   ```
4. Активируйте:
   ```bash
   sudo systemctl daemon-reload
   sudo systemctl enable --now aida-bot
   ```

## Реклама и фоновая рассылка

Реклама показывается двумя способами:

1. **При выдаче серии** — если пользователю пора (прошёл интервал), перед видео отправляется рекламный пост.
2. **Фоновая рассылка** — бот сам периодически проходит по пользователям и отправляет рекламу тем, кому пора.

Настройки (в админ-панели → «📢 Реклама»):

- **➕ Добавить рекламу** — добавить новый рекламный пост (см. ниже).
- **📋 Список рекламы** — просмотр, включение/выключение и удаление постов.
- **⚙️ Интервал рекламы** — раз в N часов и/или минут показывать рекламу каждому пользователю.
- **🔁 Рассылка** — включить/выключить фоновую рассылку.
- **📤 Разослать сейчас** — немедленно отправить рекламу всем, кому пора.

### Как добавить рекламный пост

1. «📢 Реклама» → **«➕ Добавить рекламу»**.
2. Пришлите контент одним из способов:
   - **текст** — станет текстом объявления;
   - **одно фото или видео** — с подписью (подпись станет текстом объявления);
   - **альбом** — несколько фото/видео сразу (выберите их вместе при отправке). Подпись ставится на первый элемент и отправляется как общий текст поста.
3. Введите текст кнопки (или `-` без кнопки).
4. Введите ссылку кнопки (или `-` без ссылки).

> Для альбомов Telegram не поддерживает inline-кнопки внутри самого альбома, поэтому кнопка (если задана) отправляется отдельным сообщением сразу после альбома.

Логика: у каждого пользователя хранится `last_ad_show`. Если с этого момента прошло не меньше заданного интервала — бот отправляет следующий активный рекламный пост по ротации и обновляет `last_ad_show`.

Защита от FloodWait: отправка идёт с паузой между сообщениями, а `TelegramRetryAfter` обрабатывается автоматически. Пользователи, заблокировавшие бота, помечаются и исключаются из дальнейших рассылок.

## Важное примечание по безопасности

Реальный токен бота хранится только в `.env`. Никогда не коммитьте `.env` в git. Если токен попал в публичный репозиторий — отзовите его у @BotFather и получите новый.
